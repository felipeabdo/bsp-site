# Fotografias temporárias do site

As páginas usam fotografias gratuitas do Pexels carregadas diretamente pelo CDN `images.pexels.com`. Elas são imagens ilustrativas de carnaval, percussão e festivais; não são registros oficiais do Bloco Santo Pecado. Veja fotógrafos, páginas originais e a licença em `ASSETS-PEXELS.md`.

Para trocar pelas fotos oficiais do bloco, atualize os valores de `P` em `src/lib/gallery.ts` e os campos `photo` em `src/app/historia/page.tsx`.
